# GNOME Cloud Backup (Google Drive Sync)

Нативное графическое приложение (GTK4 + Libadwaita) и CLI-скрипт для полного резервного копирования и восстановления системных настроек GNOME в облако **Google Диск**.

## 🚀 Что сохраняется в резервной копии

1. **Системные настройки и GNOME Tweaks** (`dconf dump /`):
   - Шрифты, темы оформления (Adwaita, темная/светлая тема), обои
   - Расположение и поведение кнопок окон (развернуть, свернуть, закрыть)
   - Поведение мыши, тачпада, сочетания клавиш (hotkeys)
   - Рабочие столы, настройки Mutter и оконного менеджера
2. **Все расширения GNOME Shell и их параметры**:
   - Пользовательские расширения из `~/.local/share/gnome-shell/extensions`
   - Конфигурации и настройки каждого расширения (`/org/gnome/shell/extensions/`)
   - Список включенных расширений (`enabled-extensions`)
3. **Папка ~/SystemFiles**:
   - Все файлы и скрипты из `~/SystemFiles`
   - ⚠️ Папка `asusctl` внутри `SystemFiles` **автоматически исключается** из архива
4. **Скрипты и задачи в Cron**:
   - Пользовательское расписание `crontab -l`
5. **Приложения в автозапуске**:
   - Все файлы конфигурации запуска `~/.config/autostart/*.desktop`
6. **Курсор мыши**:
   - Темы курсоров из `~/.icons` и `~/.local/share/icons`
   - Активная тема курсора и размер из `org.gnome.desktop.interface`

---

## ☁️ Как работает интеграция с Google Диском

Приложение использует нативную интеграцию **GNOME Online Accounts** (GVfs `google-drive://`).
- Никаких сторонних библиотек или сложных регистраций в Google Cloud Console.
- Если аккаунт Google подключен в **Параметры GNOME -> Сетевые учетные записи**, программа автоматически обнаруживает Google Диск и создает папку `GnomeBackups` в вашем «Моем диске».
- Загрузка и скачивание происходят с отображением реального прогресса в байтах и процентах в фоновом потоке без зависания интерфейса.

## 🖥️ Запуск и использование

### 1. Графический интерфейс (GTK4 / Libadwaita)
Вы можете запустить приложение:
- Из меню приложений GNOME: найдите **GNOME Cloud Backup** (или «Резервное копирование»)
- Или выполнив в терминале:
  ```bash
  gnome-gdrive-backup
  ```

В приложении доступны три вкладки:
- **Резервное копирование**: выбор компонентов флажками, кнопка «Создать и загрузить резервную копию», шкала прогресса и журнал.
- **Восстановление**: список архивов прямо с Google Диска с датами и размерами, кнопка «Восстановить» в один клик, а также возможность восстановить из локального файла `.tar.gz`.
- **Автоматизация**: настройка автоматического создания копий по расписанию в crontab (например, ежедневно в 21:00) и команды для терминала.

---

### 2. Командная строка (CLI)

Скрипт полностью автономен и может выполняться без GUI (например, по cron или по SSH):

```bash
# Создать бэкап и выгрузить на Google Диск:
gnome-gdrive-backup --backup

# Посмотреть доступные архивы на Google Диске:
gnome-gdrive-backup --list

# Восстановить из последней копии в облаке:
gnome-gdrive-backup --restore latest

# Восстановить из конкретной копии на Google Диске:
gnome-gdrive-backup --restore gnome-backup-2026-10-22_16-45-00.tar.gz

# Восстановить из локального файла:
gnome-gdrive-backup --restore /путь/к/файлу.tar.gz

# Создать только локальный архив без выгрузки в облако:
gnome-gdrive-backup --backup --no-upload -o ~/my_backup.tar.gz
```

## 🔄 Восстановление на чистой системе

Если вы переустановили систему или перешли на новый компьютер:
1. Подключите ваш Google аккаунт в **Параметры -> Сетевые учетные записи**.
2. Запустите скрипт или приложение:
   ```bash
   gnome-gdrive-backup --restore latest
   ```
3. Приложение скачает архив из папки `GnomeBackups`, распакует расширения, восстановит `~/SystemFiles` (сохраняя существующий `asusctl`, если он уже установлен), применит crontab, скопирует курсоры и выполнит `dconf load /` для мгновенного применения всех настроек GNOME Tweaks.
